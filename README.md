# 🐍 Ejercicios de Lógica en Python

Este es un pequeño repositorio donde guardo las actividades y ejercicios prácticos de programación que voy haciendo en clase.

## 🚀 ¿Cómo ejecutarlos?

1. **Clona el repositorio:**
   ```bash
   git clone https://github.com
   ```

2. **Entra a la carpeta del proyecto:**
   ```bash
   cd TU_REPOSITORIO
   ```

3. **Corre el ejercicio que quieras probar:**
   ```bash
   python nombre_del_archivo.py
   ```

## 🛠️ Requisitos
* Tener instalado Python 3.
